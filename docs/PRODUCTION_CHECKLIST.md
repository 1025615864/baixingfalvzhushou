## 📋 代码质量检查

### 前端
- [ ] TypeScript类型检查通过 (`npx tsc --noEmit`)

- [ ] 生产构建成功 (`npm run build`)
- [ ] 无console.log残留（除warn/error）

### 后端
- [ ] 测试覆盖率 ≥ 60% (`pytest --cov-fail-under=60`)
