### 任务 2.1: 完善 Settings 类型提示

**问题描述**：
`settings.py` 使用 `__getattr__` 属性代理，IDE 无法提供自动补全。

**解决方案**：
使用 `typing.TYPE_CHECKING` 提供类型提示，或显式定义所有属性。

```python
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    # 仅为类型检查器提供提示
    app_name: str
    debug: bool
    environment: str
    # ... 其他属性

class Settings:
    def __getattr__(self, name: str):
        # 保持运行时行为
        ...
```

**验收标准**：
- [ ] IDE 自动补全 settings.xxx
- [ ] 类型检查无错误
- [ ] 运行时行为不变
