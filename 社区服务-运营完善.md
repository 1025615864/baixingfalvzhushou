## 三、运营后台 API 设计

### 3.1 新增路由结构

```
当前已有:
├── routers/admin.py         # 基础管理 (审核+举报+统计)

需要扩展为:
├── routers/ops/             # 运营后台路由模块
│   ├── __init__.py
│   ├── auth.py              # 运营人员认证 + 角色校验
│   ├── content.py           # 内容审核工作台
│   ├── topic_ops.py         # 话题运营
│   ├── user_ops.py          # 用户运营
│   ├── analytics.py         # 数据分析
│   ├── config.py            # 社区配置管理
│   └── audit_log.py         # 操作审计日志
│
├── services/ops/            # 运营业务逻辑
│   ├── __init__.py
│   ├── ops_auth_service.py  # 运营角色+权限
│   ├── content_ops_service.py
│   ├── topic_ops_service.py
│   ├── user_ops_service.py
│   ├── analytics_service.py
│   ├── config_service.py
│   └── audit_service.py
│
├── models/
│   ├── ops_role.py          # 运营角色+权限表
│   ├── ops_audit_log.py     # 操作审计日志表
│   ├── ops_config.py        # 社区运营配置表
│   ├── user_penalty.py      # 用户处罚记录表
│   └── announcement.py      # 社区公告表
```

### 3.2 完整 API 端点设计

#### 运营认证与角色

```
前缀: /api/v1/community/ops

# 运营人员登录（复用平台账号，校验社区运营角色）
POST   /ops/auth/login
       → 验证平台账号 + 校验是否有社区运营角色
       → 返回带运营角色信息的 Token

# 角色管理（仅总监）
GET    /ops/roles                    查看所有运营人员及角色
POST   /ops/roles/assign             分配运营角色
       { user_id: 123, role: "content_mod" }
DELETE /ops/roles/{user_id}          撤销运营角色
GET    /ops/roles/permissions        查看角色权限说明
```

#### 内容审核工作台

```
前缀: /api/v1/community/ops/content

# 审核队列
GET    /content/queue
       ?status=pending&priority=high&category=劳动纠纷&assigned_to=me
       → 待审列表（按优先级排序，支持分配给特定审核员）

GET    /content/queue/{id}
       → 审核详情：原文 + AI分析结果 + 举报记录 + 用户历史违规次数

POST   /content/queue/{id}/review
       {
           action: "approve" | "reject" | "modify",
           reason: "包含广告信息",
           modified_content: "...",      # action=modify时
           penalty: "warning" | "mute_1d" | "mute_7d" | "ban" | null
       }

# 批量操作
POST   /content/queue/batch-review
       { ids: [1,2,3], action: "approve" }

# 审核任务分配
POST   /content/queue/{id}/assign
       { assignee_id: 456 }

# 审核统计
GET    /content/stats
       ?period=today|week|month
       → {
           total_pending: 23,
           reviewed_today: 145,
           approved_rate: 0.87,
           avg_review_time_seconds: 45,
           by_reviewer: [
               { name: "张三", reviewed: 67, avg_time: 38 },
               { name: "李四", reviewed: 78, avg_time: 52 }
           ]
         }
```

#### 话题运营

```
前缀: /api/v1/community/ops/topics

# 话题管理
GET    /topics                        话题列表（含帖子数/活跃度）
POST   /topics                        创建话题板块
PATCH  /topics/{id}                   编辑话题（名称/描述/图标/排序）
PATCH  /topics/{id}/status            上线/下线话题

# 话题公告
GET    /topics/{id}/announcement      获取话题公告
PUT    /topics/{id}/announcement      设置/更新话题公告
       { content: "本版规则：...", pinned: true }

# 帖子运营
POST   /topics/posts/{id}/pin         置顶帖子
       { duration_hours: 72 }          # 定时取消置顶
DELETE /topics/posts/{id}/pin         取消置顶
POST   /topics/posts/{id}/feature     加精帖子
DELETE /topics/posts/{id}/feature     取消加精
POST   /topics/posts/{id}/recommend   推荐到首页
DELETE /topics/posts/{id}/recommend   取消推荐

# 推荐位管理
GET    /topics/recommendations        当前推荐位列表
PUT    /topics/recommendations        批量更新推荐位
       { slots: [
           { position: 1, post_id: 123, label: "热门讨论" },
           { position: 2, post_id: 456, label: "律师解答" }
       ]}
```

#### 用户运营

```
前缀: /api/v1/community/ops/users

# 用户查询
GET    /users/search
       ?keyword=张三&status=active&has_violation=true
       → 用户列表 + 发帖数 + 违规次数 + 当前状态

GET    /users/{id}/profile
       → 社区画像：发帖数/评论数/点赞数/被举报数/违规记录/处罚历史

GET    /users/{id}/posts              该用户的所有帖子
GET    /users/{id}/comments           该用户的所有评论
GET    /users/{id}/violations         该用户的违规历史

# 用户处罚
POST   /users/{id}/penalty
       {
           type: "warning" | "mute" | "ban",
           duration_hours: 24,          # mute时必填
           reason: "多次发布广告内容",
           related_post_id: 789,        # 关联的违规帖子
           notify_user: true            # 是否通知用户
       }

DELETE /users/{id}/penalty            解除处罚（提前解禁）
       { reason: "用户申诉通过" }

# 用户申诉
GET    /users/appeals                 申诉列表
GET    /users/appeals/{id}            申诉详情
POST   /users/appeals/{id}/handle
       { action: "accept" | "reject", reason: "..." }

# 系统通知
POST   /users/{id}/notify
       { title: "...", content: "...", type: "warning" | "info" }

POST   /users/broadcast
       {
           target: "all" | "topic:劳动纠纷" | "active_7d",
           title: "社区公告",
           content: "..."
       }
```

```

# 核心看板
GET    /analytics/overview

       → {

               active_users: +12.3%,

# 趋势分析
GET    /analytics/trends
       ?metrics=posts,comments,users&period=30d&granularity=day
       → 时间序列数据（供前端图表渲染）

# 话题分析
GET    /analytics/topics
       → 各话题：帖子数/评论数/活跃用户数/增长率 排行

# 内容质量分析

       → {

           lawyer_participation_rate: 0.15,

       → {

           avg_session_duration: 480,    # 平均停留秒数

       ?type=overview|posts|users|moderation
       &format=csv|xlsx

       → 文件下载
```

#### 社区配置管理

```
前缀: /api/v1/community/ops/config

# 社区规则配置
GET    /config/rules
PUT    /config/rules
       {
           post_min_length: 20,             # 帖子最短长度
           post_max_length: 50000,          # 帖子最长长度
           comment_max_length: 2000,
           posts_per_day_limit: 5,          # 每日发帖上限
           comments_per_hour_limit: 20,
           new_user_post_delay_hours: 24,   # 新用户发帖等待期
           auto_close_days: 90,             # 帖子自动关闭天数
           require_approval_for_new_users: true,
           allow_anonymous_view: true,
           lawyer_badge_enabled: true
       }

# 敏感词库管理
GET    /config/sensitive-words
       ?category=政治|广告|诈骗|法律误导
POST   /config/sensitive-words
       { words: ["xxx", "yyy"], category: "广告" }
DELETE /config/sensitive-words
       { words: ["xxx"] }
POST   /config/sensitive-words/import     批量导入
GET    /config/sensitive-words/export     导出

# 自动审核规则
GET    /config/auto-moderation
PUT    /config/auto-moderation
       {
           ai_review_enabled: true,
           ai_confidence_threshold: 0.7,     # AI置信度阈值
           auto_reject_threshold: 0.95,      # 自动拒绝阈值
           new_user_always_review: true,      # 新用户帖子必审
           reported_threshold: 3,             # 被举报N次自动下架
           link_in_post_trigger_review: true  # 含链接触发审核
       }
```
